
# Мои заметки

## Введение в командную строку Bash

> Bash - это консоль (CLI) и скриптовый ЯП

### Управление Терминалом

Сдвинуть вверх лог выполненных ранее команд
`Crtl-L`

или с очисткой всего лога
```shell
clear
```
Сбросить настройки терминала и очищает экран
```shell
reset
```
Показать историю команд
```shell
history
```
Выполнить нужную коману из списка **History**
```shell
!53
```
где **53**  - это № команды из списка

Выполнить предыдущую команду
```shell
!!
```
Перелистывание ранее введённых команд
`Стрелка вверх/Стрелка вниз`

Автодополнение команд выполнятся по `TAB`

`Ctrl+C` - остановить запущенный в консоле процесс по

### Файловые операции

Получить структуру каталогов и файлов
```shell
tree
```
Показать абсолютный путь текущей директории
```shell
pwd
```
Показать содержимое текущего каталога
```shell
ls
```
Показать содержимое указанного каталога
```shell
ls dir_name
```
Показать подробное содержимое текущего каталога
```shell
ll
```
или
```shell
ls -all
```
включая скрытые файлы и папки

Примеры скрытых файлов и папок: `.gitignore` и `.git`

Показать подробное содержимое указанного каталога
```shell
ll dir_name
```
Показать содержимое в виде дерева
```shell
tree
```
Вернуться в домашний каталог текущего пользователя
```shell
cd ~
```
Вернуться в предыдущую папку
```shell
cd -
```

Знаки:
- `\` - обратный слэш (бэкслэш) - признак каталога, Windows
- `/` - прямой слэш - признак каталога, Unix/Linux/Android/macOS,iOS,BSD:
- `|` - вертикальный слэш - признак разделения команд пользователя
- `~` - тильда, признак домашнего каталога текущего пользователя

Зайти в нужный каталог
```shell
cd dir_name
```
где `dir_name` - это имя нужного вам каталога

Выйти из текущего каталога на 1 шаг вверх
```shell
cd ..
```
Выйти из текущего каталога на 2 шага вверх
```shell
cd ../..
```

Правила именования каталогов и файлов:
1. Только по-английски
1. Без пробелов и спец.символов
1. Если имя файла или каталога состоит из нескольких англ.слов., то имя можно создать так: `firstOfall` или `first_of_all`
1. В имени файлов лучше всегда указывать расширение `fileName.txt`

> **Важно:** для программирования прописные и строчные буквы - это разные буквы. `w` и `W` - это разные буквы

#### Создание файлов и каталогов

Создание пустых файлов
```shell
touch file_name.txt
```
Получить ин-фу по указанному файлу:
```shell
file newFile.txt
```
редактировать текстовый файл
```shell
micro file_name.txt
```
- `micro`- тектовый редактор командной строки
- Сохранить по `Ctrl+S` и выйти из редактора по `Ctrl+Q`

Переименовать файл
```shell
mv old_name new_name
```
Создать новую папку
```shell
mkdir NewDir
```
копирование файла
```shell
cp name_file.txt NewFolder/
```
переместить файл
```shell
mv file.txt TargetName
```
Удалить файл
```shell
rm delFile.txt
```
Удалить папку
```shell
rm -rf DelFolder
```
Создать несколько файлов
```shell
touch {1..3}.txt
```
Создать несколько каталогов
```shell
mkdir folderName{1..4}
```
Удалить содержимое текущего каталога
```shell
rm -rf *
```
Удалить сразу несколько файлов по маске
```shell
rm {1..3}.js
```

Создать структуру проекта:
```
project/
├── css/
├── js/
├── img/
│   └── ico/
├── fonts/
└── pages/
```
Создать такую структуру одной командой:
```shell
mkdir -p project/{css,js,img/ico,fonts,pages}
```

Программа на C++
```cpp

//#include <unistd.h>
#include <thread>

int main() {
    puts("Hello\nЖдём 2 ~сек...");
    //usleep(2000'000);

    return 0;
}
```
Скомпилировать код на C++
```shell
g++ main.cpp -o main.bin
```
Запустить бинарный файл
```shell
./main.bin
```
Показать используемые программой библиотеки
```shell
ldd ./main.bin
```
Покать время выполнения скрипта или программы
