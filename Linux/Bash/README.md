## ⚡ Горячие клавиши

### 🖥️ Терминал

|   Клавиша  | Действие                       |
| :--------: | ------------------------------ |
| `Ctrl + L` | Очистить экран терминала       |
| `Ctrl + C` | Остановить текущую команду     |
| `Ctrl + D` | Выйти из shell / закрыть ввод  |
| `Ctrl + Z` | Приостановить текущий процесс  |
| `Ctrl + S` | Приостановить вывод в терминал |
| `Ctrl + Q` | Возобновить вывод              |
| `Ctrl + R` | Поиск по истории команд        |
| `Ctrl + G` | Отменить поиск                 |

> 💡 `Ctrl + L` не удаляет историю и не закрывает процессы — он просто очищает отображение терминала.

---

## ⌨️ Редактирование команды

|   Клавиша  | Действие                      |
| :--------: | ----------------------------- |
| `Ctrl + A` | В начало строки               |
| `Ctrl + E` | В конец строки                |
| `Ctrl + B` | На символ назад               |
| `Ctrl + F` | На символ вперёд              |
|  `Alt + B` | На слово назад                |
|  `Alt + F` | На слово вперёд               |
| `Ctrl + U` | Удалить всё слева от курсора  |
| `Ctrl + K` | Удалить всё справа от курсора |
| `Ctrl + W` | Удалить слово слева           |
|  `Alt + D` | Удалить слово справа          |
| `Ctrl + Y` | Вставить удалённый текст      |
| `Ctrl + T` | Поменять местами два символа  |
|  `Alt + T` | Поменять местами два слова    |

## 🕘 История команд

| Клавиша / команда | Действие                                 |
| :---------------: | ---------------------------------------- |
|        `↑`        | Предыдущая команда                       |
|        `↓`        | Следующая команда                        |
|     `Ctrl + R`    | Найти команду в истории                  |
|     `history`     | Показать историю                         |
|        `!!`       | Повторить последнюю команду              |
|       `!123`      | Выполнить команду №123                   |
|       `!-2`       | Выполнить команду 2 шага назад           |
|        `!$`       | Последний аргумент предыдущей команды    |
|     `sudo !!`     | Повторить последнюю команду через `sudo` |

### 🔎 Поиск по истории

Нажми:

```text
Ctrl + R
```

Начни печатать часть команды:

```text
(reverse-i-search)`docker': docker compose up
```

Повторное `Ctrl + R` ищет следующий результат.

## 📜 Прокрутка терминала

Если нужно посмотреть предыдущий вывод:

```text
Shift + PageUp
```

⬆️ Прокрутить вверх

```text
Shift + PageDown
```

⬇️ Прокрутить вниз

В некоторых терминалах также работают:

```text
Shift + ↑
Shift + ↓
```

> ⚠️ Это зависит от самого терминала, а не от Bash.

## 🧹 Очистка

### Очистить видимый экран

```bash
clear
```

или:

```text
Ctrl + L
```

### Очистить экран и терминальный буфер

```bash
clear && printf '\e[3J'
```

### Полностью сбросить терминал

```bash
reset
```

> `reset` полезен, если терминал начал отображать символы или цвета неправильно.

# 🧭 Навигация

| Команда     | Что делает                        |
| ----------- | --------------------------------- |
| `pwd`       | Показать текущую директорию       |
| `ls`        | Список файлов                     |
| `ls -la`    | Все файлы + подробная информация  |
| `cd folder` | Перейти в папку                   |
| `cd ..`     | На уровень выше                   |
| `cd ~`      | В домашнюю директорию             |
| `cd -`      | Вернуться в предыдущую директорию |

### Быстрые переходы

```bash
cd /
```

Корень системы.

```bash
cd ~
```

Домашняя директория.

```bash
cd -
```

Предыдущая директория.

# 📁 Работа с файлами

| Команда        | Действие                   |
| -------------- | -------------------------- |
| `touch file`   | Создать файл               |
| `mkdir folder` | Создать папку              |
| `cp file dir/` | Скопировать                |
| `mv file dir/` | Переместить                |
| `rm file`      | Удалить файл               |
| `rm -r folder` | Удалить папку              |
| `cat file`     | Показать содержимое        |
| `less file`    | Открыть файл для просмотра |

# 🔍 Поиск

### Найти файл

```bash
find . -name "file.txt"
```

### Найти текст

```bash
grep "text" file.txt
```

### Найти текст рекурсивно

```bash
grep -r "text" .
```

### Найти команду

```text
Ctrl + R
```

# 🚀 Полезные комбинации

### Выполнить предыдущую команду с sudo

```bash
sudo !!
```

### Создать папку и сразу перейти в неё

```bash
mkdir project && cd project
```

### Выполнить несколько команд

```bash
command1 && command2
```

Вторая команда выполнится только если первая успешна.

### Выполнить независимо от результата первой

```bash
command1 ; command2
```
