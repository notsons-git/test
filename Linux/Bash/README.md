# Bash

## Управление

Сдвинуть лог вверх
`Ctrl+L`

Очистить экран
`Clear`

Получить историю
```shell
history
```

Перелистывание ранее введенных команд
`Стрелка вверх/вниз`

Выполнить команду из hisrory
```shell
!!
```

Выполнить указанную программу из списка
history
```shell
!45
```

Останоить запущенный процесс в консоле
`Ctrl+C`

### Файловые операции

Получить структуру каталогов и файлов
```shell
tree
```

Получить абсолютный путь к текущему каталогу
```shell
pwd
```

Получить содержимое текущего каталога
```shell
ls
```
или
```shell
ls -all
```
или показать содержимое указанной папки
```shell
ls Dir_name
```

Правила именования каталогов и файлов
1. Только по английски
1. Без пробелов и спец симполов
1. Если имя файла или каталога состоит из нескольких англ слов, то имя можно создать так: `firstOFall` или `first_of_all`
1. В имени файлов лучше всегла указывать расширение `filename.txt`

Выйти из текущей папки
```shell
cd ..
```

Вернуться в предыдущую папку
```shell
cd -
```

Зайти в указанную папку
```shell
cd Dir_name
```

Знаки:
`\` - обратный слэш
`/` - прямой слэш
`|` - вертикальный слэш

Windows:
`\` - корневой каталог
Unix/Linux/Android/macOS, iOS, BSD:
`/` - корневой каталог

Выйти из текущего каталога на 2 шага вверх
```shell
cd ../..
```

### Создание файлов



Переименовать файл
```shell
mv old_name new_name
```

Переместить файл
```shell
mv file.txt new_name
```

Удалить файл
```shell
rm filename
```

Удалить папку
```shell
rmdir foldername
```

Создать несколько файлов
```shell
touch {1..10}.txt
```

Создать несколько каталогов
```shell
mkdir folderName{1..10}
```

Удалить содержимое текущего каталога
```shell
rm -rf *
```

Создать структуру проекта
```
project/
├── css/
├── js/
├── img/
│   └── ico/
├── fonts/
└── pages/
```

Создать структуру одной командой
```shell
mkdir -p project/{css,js,img/ico,fonts,pages}
```

### Linux

Имя компьютера
```shell
hostname
```

Локальный ip
```shell
hostname -i
```

Сетевая информация
```shell
ipconfig
```
или
```shell
ip -c r
```

Пинг
```shell
ping google.com
```
или определённое колличество раз
```shell
ping -c 5 google.com
```

Получть инфу о домене
```shell
whois ozon.ru
```

Получить порты
```shell
netstat -an
```

Получить маршруты
```shell
route
```

Выйти из сеанса пользователя
```shell
exit
```

Перезагрузить
```shell
reboot
```

Выключить
```shell
shutdown
```

Показать время
```shell
date
```

Календарь
```shell
cal
```
или
```shell
cal 2027
```

Получить общую инфу по системе
```shell
fastfetch
```
