# Самостоятельная работа по Bash программированию

Практическая работа по Bash: простые скрипты, работа с файлами, создание структуры проекта и анализ GitHub-репозитория через API.

## Что внутри

| Файл | Задание |
|---|---|
| `1_greeting.sh` | Приветствие пользователя |
| `2_sum.sh` | Сумма двух чисел |
| `3_even.sh` | Проверка числа на чётность |
| `4_project_structure.sh` | Создание структуры веб-проекта |
| `5_line_count.sh` | Подсчёт строк в файле |
| `6_password.sh` | Генерация пароля длиной 8 символов |
| `7_find_files.sh` | Поиск файлов по расширению |
| `8_github_stats.sh` | Анализ GitHub-репозитория через публичный API |

## Требования

Для заданий 1–7 используется **Git-Bash**.

Для задания 8 используется **Ubuntu WSL**.

Необходимые программы для задания 8:

- `curl`
- `jq`

Проверить их наличие:

```bash
curl --version
jq --version
```

Если они отсутствуют:

```bash
sudo apt update
sudo apt install curl jq
```

## Запуск

Перейдите в папку проекта:

```bash
cd путь/к/репозиторию
```

Запуск первого скрипта:

```bash
sh 1_greeting.sh
```

Аналогично запускаются задания 2–7:

```bash
sh 2_sum.sh
sh 3_even.sh
sh 4_project_structure.sh
sh 5_line_count.sh
sh 6_password.sh
sh 7_find_files.sh
```

## Задание 8: GitHub Repository Analyzer

Скрипт принимает репозиторий в формате:

```text
owner/repository
```

Пример:

```bash
sh 8_github_stats.sh tensorflow/tensorflow
```

Скрипт получает через GitHub API:

- название репозитория;
- количество звёзд;
- количество форков;
- количество открытых issues;
- владельца репозитория;
- дату последнего обновления.

Цвета:

- звёзды — жёлтый;
- форки — зелёный;
- issues больше 100 — красный;
- issues 100 или меньше — жёлтый.

Также предусмотрена обработка:

- отсутствия `curl`;
- отсутствия `jq`;
- неправильного формата аргумента;
- несуществующего репозитория;
- ошибок GitHub API;
- превышения лимита API;
- некорректного ответа API.

## Проверка

Перед сдачей каждый скрипт необходимо проверить командой:

```bash
sh script.sh
```

Скрипты 1–7 проверяются в **Git-Bash**.

Скрипт 8 проверяется в **Ubuntu WSL**.

После проверки необходимо сделать скриншоты выполнения заданий и добавить их в репозиторий.

## Git

```bash
git init
git add .
git commit -m "Добавлены практические задания по Bash"
```

После создания удалённого репозитория:

```bash
git branch -M main

git push -u origin main
```
